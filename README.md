# 슈퍼 헬로우키티

드래곤볼 × 헬로키티 테마의 Unity 2D 보스전 액션 슈팅 게임입니다.

## 실행 방법

1. Unity Hub에서 이 저장소 폴더를 프로젝트로 추가합니다.
2. Unity **6000.5.1f1**로 프로젝트를 엽니다.
3. 패키지 설치와 에셋 임포트가 완료되면 `Assets/Scenes/SampleScene.unity`를 엽니다.
4. Play를 누르고 시작 화면에서 난이도를 선택합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← / → 또는 A / D | 좌우 이동 |
| Z | 점프 / 이단 점프 |
| X | 발사 |
| Esc | 일시정지 |
| R | 게임 오버 후 재시작 |

## 주요 기능

- Easy / Normal 난이도 선택
- 5발 발사 후 자동 재장전
- 레이저, 탄막, 원반, 하트, 원기옥 보스 공격
- 보스 체력에 따른 페이즈 전환
- 일시정지, 재시작, 보스 처치 및 엔딩 연출

## 프로젝트 구성

- `Assets/script`: 플레이어, 보스, UI 및 연출 스크립트
- `Assets/Scenes`: 게임 씬과 입력 설정
- `Assets/Resources`: 런타임에 불러오는 UI 이미지, 음원 및 프리팹
- `Packages`: 패키지 의존성
- `ProjectSettings`: Unity 프로젝트 설정

Unity 캐시, 로컬 사용자 설정과 빌드 결과물은 버전 관리에서 제외합니다.
